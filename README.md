# Mentor Cards Web

A simple and responsive mentor cards website built with **HTML and CSS**. It showcases mentor profiles in clean, modern cards with their expertise and experience.

## Features

* Responsive design
* Clean mentor profile cards
* Simple and modern UI
* Built with HTML & CSS

## Technologies

* HTML5
* CSS3

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/ghezaalbahar-gif/Mentor-cards-web.git
   ```
2. Open `index.html` in your browser.
